# AfterLoop brand kit

- `AGENTS.md` — regole per opencode / agenti di codice: copiarlo nella root del repo.
- `tokens/` — `tokens.css` (variabili CSS + componenti base), `tokens.json`, `tailwind.preset.js`.
- `logo/` — marchio e lockup (su scuro, su chiaro, mono), `favicon.svg`, `app-icon.svg`.
- `icons/` — 36 icone SVG singole, `sprite.svg`, `icons.tsx` (componente React).
- `patterns/` — afterglow 16:9 e 4:5, anelli del loop, griglia di nodi.
- `social/` — `og-image.svg` (1200x630), `linkedin-banner.svg` (1584x396).

Font (Google Fonts): Geist, Geist Mono, Instrument Serif. I lockup SVG usano `<text>`: installa Geist per esportarli in PNG, oppure convertili in tracciati con Inkscape.
Per PNG, ICO e apple-touch-icon parti da `logo/favicon.svg` e `logo/app-icon.svg`.
